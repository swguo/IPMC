# 旅途手帳

手機優先的 GitHub Pages 旅程 dashboard。各主題為獨立分頁，頂端固定工具列與目前主題名稱，功能選單預設收起，可點擊顯示／隱藏，選擇主題後自動收起；支援主題網址片段（例如 `#hotel`），離線重開後保留所選主題。公開目錄 `site/` 只包含靜態程式與加密旅程資料，不需要建置工具或外部 CDN。

## 安全方式

密碼透過 PBKDF2-SHA256（600,000次、隨機salt）衍生 AES-256-GCM 金鑰，在瀏覽器本機解密。密碼、原始票券與明文旅程不納入此儲存庫。這是靜態網站的密碼加密解鎖，不是伺服器登入；公開密文仍可被下載嘗試猜密碼，請保留自動產生的強密碼。

解鎖後資料只放在頁面記憶體，不存localStorage；僅清單勾選狀態存於本機。閒置10分鐘或離開頁面會鎖定。離線快取只包含程式與密文，不快取密碼及明文。鎖定不會清除已複製至剪貼簿的資訊。請避免在公共裝置開啟。

## 本機查看

```sh
python3 -m http.server 8000 --directory site
```

以瀏覽器開啟本機8000埠；正式部署需HTTPS，供Web Crypto及Service Worker運作。首次線上載入並完成快取後可離線解鎖；地圖、電話及外部議程依裝置或網路條件運作。

## GitHub Pages 發布

1. 將此儲存庫內容推送至 `swguo/IPMC` 的 `main`。
2. GitHub 儲存庫 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**。
3. 確認 `Deploy travel dashboard` 工作流程成功；必要時至 Actions 手動執行。
4. 預期專案網址為 `https://swguo.github.io/IPMC/`，僅在部署成功後可用。

Actions僅上傳 `site/`。不要將原始PDF、明文筆記、密碼或私密資料加入Git。也可在Pages設定使用 `main` 根目錄以外的自訂來源前，先採本專案的Actions部署方式。

## 更新資料／密碼

私密HTML與密碼檔放在checkout外，對該檔案採僅本人可讀權限。編輯私密HTML後執行：

```sh
node scripts/encrypt.mjs /private/content.html /private/dashboard.password
node tests/validate.mjs
```

加密工具預設要求至少16字元密碼；若明確選用較短密碼，可加上 `--allow-short-password`（較容易遭離線猜測）。完整密碼由私密檔讀取，不應放命令列。HTML會在解鎖後作為可信模板呈現，只可加入可信內容，外部文件文字需先HTML escape。更新發布時請同時遞增 `site/sw.js` 的快取版本。更換密碼後舊版密文及舊密碼仍可能存在Git歷史或其他裝置的離線快取；改密碼無法撤回曾經公開的版本。

## 驗證

`node tests/validate.mjs` 檢查公開資產範圍、密文格式與個資未明文外洩。本次另以真實瀏覽器驗證錯誤密碼、正確解鎖、日期切換、清單保留、手機版、複製、手動鎖定、自動鎖定及離線解鎖。

地鐵分頁提供機場到飯店與飯店到機場的獨立方向流程、機場步行指引及營運資料來源。既有 draw.io 路線內容已匯出為去程與回程 PNG，直接嵌入各方向分頁，支援點擊放大及文字版步驟；不再提供流程圖下載按鈕。圖片隨旅程密文保存，可離線查看。營運時刻為使用者提供資訊，未獨立確認當日班表；最新計畫改為10/31晚間23:00前搭地鐵到機場過夜；04:00為預計報到時間，仍需核對地鐵末班、夜間可停留區與東航櫃檯開放時間。另有獨立轉機手冊，提供行李直掛／重掛、第二段登機證及出境轉機流程的分流說明與地勤詢問清單。

旅行與參加會議檢查清單各有獨立主題分頁，依文件、交通、裝備、簡報備份等分類，顯示各清單的完成進度。既有勾選鍵保留，新列印與多處備份項目採各自獨立鍵；勾選狀態僅存目前瀏覽器，不跨裝置同步。

QA速查分頁整合使用者提供的TRACE問答頁，以2026/10/26英文Markdown為準，提供37題、7分類、關鍵字搜尋、41頁投影片篩選及確認問題提示。問答資料與原頁面結構存入旅程密文，公開的 `qa.js`／`qa.css` 僅包含介面程式及樣式。介面使用Shadow DOM隔離，避免影響平台導覽；移除外部字型依賴，支援離線查閱。切換主題暫停螢幕常亮，鎖定時移除問答內容；不將問答或搜尋內容存於localStorage；37題提供依新版英文製作的中文題名與理解摘要，可切換中文、English或雙語；英文補充完整保留，中文摘要不取代原始數據及限制說明。

演講稿分頁整合上傳的英文Markdown原稿，含發音指南、時間表、33頁正文與8頁備用內容。提供頁碼選擇及上一頁／下一頁，僅將頁碼保存在目前瀏覽器。原稿10:00場次註記與目前議程不同，另註明最新場次10:30、個人12:30–13:00，未改寫原文。新版共41頁，時間表約20.0分鐘，與QA頁碼一致。內容隨旅程加密，支援離線閱讀。


## QA鍛鍊

解鎖後從功能選單進入「QA鍛鍊」，展開「OpenAI API設定」輸入自己的API金鑰，再選分類、題目、難度及語速。按「開始／下一題」會變換英文問法並自動嘗試播放 `onyx` 男性聲線；若瀏覽器限制自動播放，請按播放器。預設先聽再看，可顯示問題與關鍵字提示。

按「開始錄音」，允許麥克風後回答；按「停止並分析」將錄音送OpenAI轉錄及分析，最長90秒。可核對或修改逐字稿，再次分析。支援手動文字回答作為錄音不支援或權限被拒時的替代方式。回饋包含模型估計分數、切題／正確／完整度、已答與遺漏重點、未獲參考支持的說法，以及精簡英文回答；僅依逐字稿評估內容，不評估發音或口音。

預設文字模型 `gpt-4.1-mini`、語音模型 `gpt-4o-mini-tts`、轉錄模型 `gpt-4o-mini-transcribe`；模型存取依API帳戶而定，可在設定中修改相容模型名稱。使用OpenAI API可能產生費用，需有API額度，與ChatGPT訂閱分開。

金鑰僅在目前瀏覽器的localStorage保存 AES-256-GCM 密文，金鑰加密所需的密鑰以旅程密碼及獨立隨機salt、PBKDF2-SHA256 600,000次衍生，不儲存旅程密碼。選擇「僅本次」則只在記憶體使用。密碼更改後須重新設定API金鑰；裝置之間不自動同步。API金鑰會在瀏覽器記憶體解密並透過Authorization標頭送到固定的 `https://api.openai.com/v1/`，不會上傳GitHub或放入網址。這是個人使用的靜態網站方案；使用中的金鑰無法對可操作該瀏覽器的人、擴充功能或開發工具保密，請使用自己的可信裝置。

相關QA內容、問題與回答會送OpenAI；錄音由使用者按鈕啟動並顯示狀態。錄音、逐字稿與評分不儲存於本機持久儲存，Service Worker不攔截或快取OpenAI請求。切換主題及鎖定會釋放麥克風、停止播放並中止請求；已送出的API請求仍可能計費。鍛鍊需網路，其他QA及講稿仍可離線使用。模型回饋不能取代論文核對；參考答案本身不是由此功能獨立查證。

### 鍛鍊功能驗證

```sh
node tests/validate.mjs
node tests/trainer-core.mjs
```

`tests/trainer-browser.cjs` 使用Playwright、模擬OpenAI API與Chromium合成麥克風，**不使用真實API金鑰或產生API費用**。先啟動本機網站，再設定 `TRAVEL_PASSWORD_FILE` 指向儲存庫外的私密旅程密碼檔。若Playwright不在Node模組路徑，設定 `PLAYWRIGHT_MODULE` 為安裝位置；可用 `CHROMIUM_PATH` 指定瀏覽器執行檔。

```sh
TRAVEL_PASSWORD_FILE=/private/dashboard.password node tests/trainer-browser.cjs
```

瀏覽器測試驗證出題、語音請求與自動播放嘗試、錄音轉錄、評分、重播、錯誤處理、金鑰加密、鎖定清除、停止錄音與請求、離線快取範圍及手機／桌面排版。正式API權限、模型可用性、聲音品質與評分結果仍需在使用者設定可用金鑰後驗證；未將模擬測試視為正式服務驗證。

Q5（分數與保留各部分結果）、Q18（資料來源與檢索池）、Q34（危險高估與整體表現）、Q35（高recall與類別崩潰）標記為加強題，加入多種問法、聽力關鍵字、簡短口說版與易錯提醒。QA鍛鍊的「★ 我的加強題」分類目前包含Q5、Q18、Q34、Q35四題；分析參考內容同步使用補強後的英文QA。
